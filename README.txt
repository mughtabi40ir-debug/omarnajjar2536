MR. KOMPRENO — calm palette and editable texts

Open index.html normally to see the customer menu.
To edit text, double-click edit.html. It opens the text editor in your web browser automatically.
Do not double-click editor.js or content.js: these are supporting files, not apps.
For your published website you can also add ?edit=1 to the URL.
Tap «تعديل النصوص», change Arabic, English, category, and product copy, then tap «حفظ ومعاينة».
This saves a preview in the current browser. Tap «تنزيل content.js» and replace the site's existing content.js with the downloaded file to publish the text for everyone.
For a GitHub Pages site, upload the new content.js into the same folder as index.html and commit the change. The visual and JavaScript files do not need another edit for later text changes.

Keep your existing assets folder beside index.html. The source files supplied for this update did not contain the images. Their expected filenames are:
assets/logo.jpg
assets/mascot.jpg
assets/baked-meat.jpg
assets/baked-corn.jpg
assets/pizza-veg.jpg
assets/pizza-meat.jpg

PRODUCT AND IMAGE EDITOR
Open edit.html, then the Products tab.
Add or delete dishes; edit Arabic/English names and descriptions, price, badge, and category.
Paste an image URL, relative path such as assets/dish.jpg, Base64 data URL, or an <img> code into the image field. You can also upload a PNG/JPG/WebP image; it is resized and included inside content.js, so the uploaded image does not need a separate upload.
Use Add Category to create a category, then select it for your dishes.
Save and preview, then download content.js and replace that file in your published site. Local preview is limited to the current browser.
